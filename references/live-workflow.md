# 直播跨页面采集与按问题计算

## 按白话需求确定取数路径

| 用户问题 | 取数页面与计算 |
| --- | --- |
| 最近直播带货稳不稳 | 达人直播列表，核对窗口，遍历所需全部场次；算场均、中位数、最高场贡献、按开播日期分组趋势。首屏只作样本，不代表完整周期 |
| 每小时卖多少钱、直播效率怎样 | 列表+场次详情，取本场GMV、销量、时长；自行GMV/小时、销量/小时，另保留平台小时指标，差异不静默覆盖 |
| 转化好不好 | 场次详情读平台“销售转化率”原值及定义；用户若问点击转化，则需要匹配点击/订单分母，不将653件/1.81万人次解释为点击订单转化 |
| 哪些商品撑起这场、竞品表现如何 | 场次详情商品列表，按(live_id,product_id)连接各页，再按确认的商品/店铺ID匹配；统计不同场次及本场商品行GMV/销量，不能用店铺总销量或全场GMV替代 |
| 是不是多款挂着不出单 | 本场动销商品数/上架商品数；若细分竞品，必须遍历相关商品列表，缺页不能将未见商品视为零 |
| 报价值不值 | 取竞品本场商品效果、同类目/价格段历史和真实成本，输入情景；全场GMV不能直接当成某新品销售预测 |

## 已验证页面路径

1. 从当前浏览器清单选择用户打开的达人。2026-11-09为Kourtney♡ / savingwithk / 7112242035939492907。复核身份、国家、直播模块周期和页码，不把示例ID固化为默认目标。
2. 达人详情“直播分析”显示每行场次链接、开播时间(GMT-5)、时长、销量、GMV、上架与动销商品数、累计观看人次及UV价值。时间保留原时区；按用户日期比较前统一时区。
3. 打开所需场次链接，例如已观察到 `/zh/live/detail/7705528508910553870`。核对场次时间和主播身份，读取数据总览：销量、销售额、人数峰值、增粉、平均成交单价、UV价值、销售转化率及GPM。
4. 滚动/点击“直播带货商品列表”，等待列表加载。每行保留商品ID与详情链接、店铺ID、价格原文、本场销量、本场销售额、佣金。列表可能先显示“全部(0)”但已出现多页商品；以加载后列表和页码交叉核对，不记假零。
5. 翻页依照当前页面控件和页码，不复用历史索引。核对首商品ID改变，按场次+商品ID去重。需要竞品效果时继续到约定范围；要全场排名/贡献时读完本场所有可访问页，再按金额排序，不能把按销量排第一页称GMV Top5。
6. 对竞品归属不明确的商品，进入其商品详情并按页面店铺链接核验；进入店铺页确认名称/主体。商品/店铺全局销量与本场归因分开保存。无明确竞品时交付观察到的商品/店铺结构，不擅自认定竞争关系。
7. 遇见趋势图/回放，只有可见可读数据才取值。本次显示“本场直播暂无回放”；不能据图猜测峰值时点、讲品片段或评论舆情。不要点击添加监控来代替只读历史分析。

## 输入扩展与口径

沿用history_analysis.py输入。live记录增加duration_seconds、viewer_visits（累计观看人次，不是独立UV）、listed_product_count、active_product_count。只在确认这些数字来自同一整场时设session_scope_verified=true。平台原值放platform_metrics，保留原标签、原文、定义和独立来源；平台平均成交单价不能擅自改名为订单客单价。

product_metrics为本场商品行数组，必填字符串id、session_id、source_url（直播商品列表证据地址）；可加product_url、shop_id、name、units、gmv、price_raw、commission_rate。每条绑定本场，其他场次数据拒收。重复行相同去重，冲突报错。product_coverage写已采集页数/条数及总页数，部分行销售额是已观察小计，不冒充全场品牌销售额。

competitors通过明确product_ids/shop_ids匹配。live_product_effects保留每场每商品，live_product_observed_gmv只累加本场商品行，不与effect_single_product_only叠加。店铺ID匹配表示店铺推广，不自动认定店铺全部商品属于单一品牌。

## 实测发现

近28天窗口2026-10-12至2026-11-08，达人页显示34场，直播列表7页，读取第一页5场；首场117商品、24页，仅采第一页5条。首场明示销售转化率3.61%、GPM $1424.03、平均成交单价$39.5，但分母/算法尚未核实，作为平台显示值保留。没有取得退货率或评论正文。

平台显示首场销售额$2.57万、时长03:33:59，同时小时销售额$8596.87；自行除时长约$7206.17/小时，差异记录。达人页与详情侧卡同称近28天，场均销售额却为$2.40万和$1.96万；不合并做趋势。平台近似展示值计算结果均标“约”。
