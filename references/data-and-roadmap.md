# 数据口径、档案与后续规划

## 用户希望支持的四项能力

1. 自然语言搜达人，例如包包类目、常做测评、近期挂车表现好、报价不超过8k、粉丝2–10万。预算须明确币种和合作单位；无法查证的条件标为待核实。
2. 定期更新达人池：首次建库，之后分层增量更新、去重并保留快照。刷新频率需结合业务需要、页面数据周期和实际账号额度。
3. 历史带货拆解：视频/直播分开看，同类目与相近价格段比较，关注单条表现中位数、爆款贡献、近期与长期趋势、竞品推广记录。
4. 自动档案：基础数据、内容标签、粉丝画像、优劣势、风险、报价来源与区间、适配合作方式。

## 建议记录结构

- 达人：平台稳定ID、昵称、Handle、国家、主页与FastMoss来源链接。
- 快照：采集时间、统计周期、粉丝、涨粉、销量、GMV、互动率、平均播放量、字段原文与缺失状态。
- 内容与商品：视频/直播ID、发布时间、品牌/商品、类目、价格段、表现、证据。
- 合作：实际报价与币种、报价日期、合作形式、寄样、回复、履约、费用与实际结果；只接收用户提供或授权读取的内部记录。
- 分析：结论、来源类型、计算口径、证据、置信度与待核实项。

档案输出：身份与来源 → 数据概览及周期 → 内容/粉丝画像 → 带货表现 → 竞品推广 → 适配形式和理由 → 风险/缺失项 → 下一步建议。

报价区分真实报价、历史成交价、模型估价。投产初期采用保守/基准/乐观情景，结合毛利、佣金、样品、物流、退款损失和投流费用计算盈亏平衡，不给无依据的精确ROI。

## 分阶段落地

先跑通自然语言条件 → 网页筛选 → 名单 → 档案 → 人工选人 → 回填实绩，再加保存条件与定期更新。目前只验证了粉丝范围搜索，其他模块属于后续规划。

FastMoss会员不代表有API权限。本技能当前走网页；未来若获得官方API权限，再独立验证接口字段与额度。页面可读不证明批量导出和无人值守可用。
